# Mobile Floating Nav 悬浮导航

Obsidian 移动端悬浮导航插件:在屏幕边缘显示**可自定义的悬浮按钮栏**,按钮**数量与功能**完全由你决定。

Obsidian 原生悬浮工具栏图标数量固定、无法编辑,本插件提供一个独立、可完全定制的悬浮导航栏:

- 按钮数量自由增删,支持上移/下移排序
- 每个按钮可配置 5 种动作
- 左侧 / 右侧悬浮、折叠收起、大小 / 间距 / 透明度 / 距边缘距离均可调
- 默认仅移动端显示,可切换到桌面端
- 安全区适配(iOS 刘海屏不遮挡)

## 安装

1. 下载 `release/mobile-floating-nav-0.1.0.zip`
2. 解压后得到 `mobile-floating-nav/` 文件夹
3. 将其放入仓库的 `.obsidian/plugins/` 目录
4. Obsidian 设置 → 第三方插件 → 重新加载 → 启用「Mobile Floating Nav 悬浮导航」

## 使用方法

启用后,手机屏幕右侧边缘出现悬浮按钮栏(默认 4 个按钮 + 底部折叠按钮)。

### 配置按钮

设置 → 第三方插件 → Mobile Floating Nav 悬浮导航:

- **添加按钮**:选择动作类型后点击「添加按钮」
- **配置按钮**:每个按钮卡片可设置
  - 名称
  - 图标(内置 200+ 常用图标,支持搜索;也可以直接输入任意 lucide 图标名)
  - 图标颜色(可选,留空跟随主题)
  - 动作类型与参数
- **排序 / 删除**:按钮卡片底部的上移 / 下移 / 删除按钮

### 动作类型

| 动作 | 参数 | 说明 |
| --- | --- | --- |
| 执行命令 | 选择命令 | 调用任意 Obsidian 命令,如命令面板、快速切换、打开日记 |
| 打开笔记 | 选择笔记 | 一键跳转到指定笔记 |
| 新建笔记 | 无 | 在当前默认文件夹新建未命名笔记并打开 |
| 返回顶部 | 无 | 当前笔记滚动回顶部(白板/PDF 视图同样有效) |
| 打开链接 | URL | 打开外部链接 |

### 快捷操作

- **长按**悬浮栏空白处(桌面端**右键**)→ 直接打开本插件设置
- 命令「显示/隐藏悬浮导航」「收起/展开悬浮导航」可绑定快捷键

## 开发

```bash
npm install          # 安装依赖
npm run typecheck    # 类型检查
npm run build        # 构建 main.js
npm run zip          # 打包 release zip
node scripts/loadtest.mjs   # 加载与逻辑测试(jsdom)
```

## 目录结构

```
src/
├── main.ts        # 插件入口:生命周期、命令注册
├── settings.ts    # 设置类型与默认配置
├── toolbar.ts     # 悬浮按钮栏渲染与动作执行
├── settingsTab.ts # 设置页面
├── icons.ts       # 内置常用图标清单
└── modals.ts      # 图标/命令/笔记选择弹窗
```
