# CardBox 卡片盒（Obsidian 插件）

Writeathon 风格卡片盒：**记录灵感 → 整理卡片 → 组合成文**。移动端优先，自包含（只依赖 Obsidian 官方 API，无需 Dataview 等第三方插件）。

## 功能（MVP）

- ⚡ **快速记录卡片**：弹幕式连续录入，保存后保持打开、自动清空，手机上零阻力收集灵感
- 📦 **卡片盒视图**：卡片列表 + 时间轴（按天分组）两种模式
- 🔍 **筛选**：全文搜索、标签 chips（支持嵌套标签 `读书/笔记`）、快捷开关（有标签 / 无标签 / 空内容 / 含任务 / 含归档）、4 种排序
- ✏️ **编辑**：点击卡片在编辑器中打开
- ☑️ **多选批量操作**：长按（触屏）或按钮进入多选 → 批量打标签、合并为文章、归档、删除
- 🌿 **子卡片**：为卡片创建关联子卡片，父卡片可展开查看子卡片
- 📄 **合并成文**：多选卡片合并生成新文章（简单拼接 / 按标题层级两种模式）
- 🗄️ **归档**：frontmatter 标记归档，不移动文件、不破坏链接，随时可逆

## 数据模型

每张卡片 = 一个独立的 Markdown 笔记，存放在可配置的文件夹（默认 `Cards/`）：

```markdown
---
id: "2026-08-09-123456-7f3"
title: "可选标题"
tags:
  - flash
  - 读书/笔记
created: 1723181696000
updated: 1723181696000
parent: "2026-08-09-120000-ab1"
children:
  - "2026-08-09-123500-cd2"
archived: false
---
卡片正文……
```

- 文件名用 id（`YYYY-MM-DD-HHmmss-xxx`），闪念卡片标题重复也不冲突，链接稳定
- 时间戳用纪元毫秒整数
- 卡片与 Obsidian 双向链接、图谱、全文搜索完全兼容

## 安装

### 桌面端
1. `npm install && npm run build`，或将 `main.js` / `manifest.json` / `styles.css` 放进 `<你的库>/.obsidian/plugins/cardbox/`
2. Obsidian → 设置 → 第三方插件 → 启用 **CardBox 卡片盒**

### 移动端
1. 把 vault 同步到手机（Obsidian Sync / iCloud / 手动复制）
2. 在手机上启用插件
3. **移动端入口**：侧栏 ribbon 卡片盒图标 + 命令面板。推荐给「快速记录卡片」绑定一个快捷键

> Obsidian 移动端底部编辑器工具栏没有稳定的插件 API，因此移动端入口为 ribbon + 命令/快捷键。

## 开发

```bash
npm run dev   # esbuild watch（配合 pjeby Hot Reload 插件热重载）
npm run build # tsc 类型检查 + 生产构建
node scripts/seed.mjs <vault路径> <数量>   # 生成测试卡片，验证大数据量性能
```

### 测试 Vault
仓库内的 `test-vault/` 已预置插件，可直接用 Obsidian 打开（设置 → 第三方插件 → 启用 CardBox 卡片盒）。
