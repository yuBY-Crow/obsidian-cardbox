# 2026-08-13

## 手机端新建卡片重设计为简单扁平（v0.6.24）

用户要求：简单扁平、少边框、正文区大、支持编辑标题、保留保存 + 连续创建。

**设计原则**：零边框零分割线，靠字号（标题 20px/600 vs 正文 16px）
与字重区分层级，正文 flex:1 撑满（实测占容器 87%）。

**结构简化**：
- 删掉 .cardbox-capture-title-row 包裹层，标题 input 直接是 contentEl 首个子元素
- 标题 placeholder 改语义化「标题」（原来是「写作就像马拉松」）
- 标题 Enter 跳正文；默认聚焦正文（正文是主角）
- 删掉 autosize 机制（flex 撑满代替动态算高度）

**样式**：容器改 --background-primary（一张纯净的纸）；
标题/正文/footer/mode 全部 border: none + background: transparent；
保存按钮是界面里唯一的实心元素；移动端 min-height 44px。

**文案**：连续模式 → 连续创建。

**又一次踩同样的坑**：styles.css 尾部「旧样式兼容块」会覆盖新样式。
上次是 .cardbox-capture-input（v0.6.22），这次是 .cardbox-capture-footer。
教训：改 CaptureModal 样式时先 grep 整个 styles.css 看有没有同名选择器
在后面重复声明，CSS 后者优先。

**测试 mock 要点**：capturetest 必须给 body 加 is-mobile 类
（否则 body.is-mobile 覆盖样式测不到），且 modal contentEl 要给
position:fixed;inset:0 模拟全屏（否则 flex:1 撑不开，正文占比断言失败）。

capturetest 26 → 29 例（零边框 5 + 透明背景 3 + 字号层级 2 + 正文占比 + 触摸区 2）。
全量 285 例通过。版本 0.6.24，提交 525fdc5。
