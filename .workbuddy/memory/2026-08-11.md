## kebab 图标真机渲染成空点（v0.6.5）

用户真机截图：view header 的竖三点正常，但卡片 kebab 只显示一个点。

**根因**：`setIcon` 对不存在的图标名**静默失败**——不报错，只挂空 SVG
（视觉上就是一个点）。lucide 在各 Obsidian 版本里对竖三点的命名不同
（旧版 `more-vertical`、新版 `ellipsis-vertical`），且 `IconName` 类型
只是 `string`，编译期无法发现。

**修复**：新增 `src/utils/icon.ts` 的 `setKebabIcon`：
- `getIcon()` 运行时探测（返回 null 即不存在），more-vertical → ellipsis-vertical
- 都缺时用 Unicode `⋮` 兜底
- 探测结果模块级缓存
- CardTile + CardExtendView 统一使用

**连带暴露的测试问题**：新增 `getIcon` import 后，5 个测试文件的 obsidian
mock/stub 全部缺这个导出而挂掉。教训已记入技能：
**新增官方 API import 必须同步更新全部 mock**（先 `grep -l "setIcon" scripts/` 找全）。

新增 `scripts/icontest.mjs` 8 例（旧版库/新版库/Unicode 兜底/探测缓存）。
全量回归通过。版本 0.6.5，提交 0b8876d，
已同步 test-vault + 真实库 + release/cardbox-0.6.5-mobile.zip。

## 新建独立插件：mobile-floating-nav（移动端悬浮导航）

用户需求：Obsidian 原生悬浮工具栏图标数量固定不可编辑，要一个能**自由增删按钮数量与配置功能**的移动端悬浮导航。

新插件目录 `mobile-floating-nav/`（与 CardBox 并存），ID `mobile-floating-nav`：
- 固定按钮栏：屏幕左/右侧竖排悬浮，可折叠成小球
- 按钮数量自由增删 + 上移/下移排序；每按钮可配 5 种动作：
  执行命令 / 打开笔记 / 新建笔记 / 返回顶部 / 打开链接
- 图标：内置 200+ 常用 lucide 清单（icons.ts），可搜索选择或手输任意 lucide 名
- 外观：按钮大小/间距/背景透明度/距边距离/位置/平台可见性（默认仅移动端）
- 长按（桌面右键）悬浮栏空白处直接打开设置页；两个命令可绑快捷键
- 安全区适配 env(safe-area-inset)

工程要点（可复用的经验）：
- 构建模板直接复制 CardBox 的 esbuild.config.mjs + tsconfig.json
- **新 obsidian 类型版本中 `App.commands` 未公开声明**（运行时存在），
  需 `(app as unknown as {...}).commands` 断言；`getNewFileParent` 需传参 `""`
- `FuzzySuggestModal.renderSuggestion` 参数是 `FuzzyMatch<TFile>` 而非 `TFile`
- CJS 产物在 ESM 测试里 `import { default }` 拿不到类，改用
  `createRequire` + `mod.default ?? mod`
- Node 22 `globalThis.navigator` 只读，jsdom 测试不要覆写
- 测试：scripts/loadtest.mjs（jsdom 模拟 Obsidian 加载 main.js），19 例全过
- 打包：scripts/zip.mjs（手写 store zip，正斜杠前缀，兼容手机解压）

产物：main.js（35KB）+ styles.css + manifest.json → release/mobile-floating-nav-0.1.0.zip；
preview.html 为手机端效果交互预览。

## 标题 fallback 增强 + 数字即展开（v0.6.6）

用户真机反馈三项问题：

### 1 卡片没有显示标题（最可能的根因）
测试库 433 张卡片只有 71 张有 title（16%），其余 fallback 到正文首行。
而 markdown 笔记首行常是 `# 标题`/`> 引用`/`- 列表`，前缀符号被用户当
成「没有显示标题」的一部分。
**修复**：新增 `extractTitle(card)`：
- 先剥成对行内 markdown（`**...**`、`*...*`、`` `...` ``、`[文本](url)`）
- 再剥首部块级前缀（# 标题、> 引用、列表、1. 有序）
- 剥光且无任何文字字符时回退「空内容」占位
**关键**：必须先处理行内再处理块级，否则块级 regex 贪吃 `**` 会破坏成对
语法、留下孤立 `**`（首轮试错由此失败）
**测试**：`scripts/titletest.mjs` 9 例覆盖：title/#标题/>引用/-列表/行内md/完全空/
孤立#/纯文本/重复首行内容

### 2 点击展开无效果 + 3 数字和时间不在一行（合并解决）
新交互设计（用户明确要求）：
- **去掉 chevron 按钮**（`.cardbox-expand-btn` 不再渲染）
- 数字本身就是交互入口
- 点击数字展开（数字加 `is-expanded` 类 → 变主题色），再点收起（恢复默认色）
- 数字从独立的 `.cardbox-tile-related` 行移除，改放 meta 行与时间同行
**顺带修展开无效果**：旧设计 chevron 区域用 wrap 委托 click，移除 chevron
后改用纯 span + stopPropagation，行为简单可靠。

**布局清理**：
- 删 `.cardbox-expand-wrap`、`.cardbox-expand-btn`、`.cardbox-tile-related` 样式
- `.cardbox-expand-count` 默认色用 `var(--background-modifier-border) +
  var(--text-maint)` 避免视觉抢眼；`is-expanded` 变 `interactive-accent`
- 长按排除列表改为 `.cardbox-expand-count`（之前是 `.cardbox-expand-wrap`）

### 再次踩「外部目录误入 git」
`mobile-floating-nav/`（D盘根目录的另一个项目）被 `git add -A` 误加进
本仓库提交——git 警告「in the working copy of mobile-floating-nav/...」暴露。
**教训**：
- `git add -A` 前必须先 `git status` 看一眼待提交文件清单
- git add 别人的代码是非常严重的污染，发现必须立刻 `git rm -r --cached`
  从索引移除（**保留**磁盘文件）+ 加入 `.gitignore` 防再误入
- 已加回，提交 `3442b8b`
